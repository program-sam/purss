# Security

Please report security problems privately, not in a public issue: use **Report a vulnerability**
under this repository's [Security tab](https://github.com/program-sam/purss/security/advisories/new).
Say what you found, how to reproduce it, and which version or commit you tested.

Reports about the hosted service at purss.app and about the code itself are both welcome. Please
don't access other people's accounts or data, and don't run tests that slow down the service for others.
